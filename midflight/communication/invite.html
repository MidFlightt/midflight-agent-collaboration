Your own four-agent cloud demo

Try MidFlight with Billing, Delivery, Booking and Notifications agents. Your demo gets a separate cloud project. Other visitors cannot access it.

You need macOS, Git, uv, tmux and a signed-in Codex CLI with ~/.codex/auth.json. Agents use your own Codex allowance. Other platforms have not been verified. No AWS account or local database is needed.

1. Save your access file

2. Install and start

Run these commands in a terminal. Use a fresh folder. Adjust the access-file path if your browser saved it elsewhere.

Open the local address printed in your terminal. All four task prompts are prepared but unsent. Press Enter in each panel to start.


3. Try a change
After the initial build finishes, tell the Delivery agent: “When a delivery is cancelled, keep a four-credit cancellation fee and refund the rest, never below zero.”


Then give the idle Billing agent a useful task: “Add regression coverage for revenue reporting across mixed confirmed and cancelled deliveries under the current shared requirements, including small totals and previously saved refunds.”


Agents check shared context during useful work, not through idle polling. Their local tests may mock peers; run the combined-code validation described in the repository before claiming integration success. Reset does not erase cloud projects.
